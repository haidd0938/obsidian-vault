## 🔥 爆款小红书文案提示词（万能模板）

### 标题生成器

```
你是一位小红书爆款标题专家。请根据以下信息生成10个爆款标题：

【内容类型】：[约稿/定制设计/武魂设定]
【目标人群】：[斗罗大陆/叶罗丽/神印王座爱好者]
【核心卖点】：[独一无二的定制设计]

要求：
1. 每个标题不超过20字
2. 必须包含数字或emoji
3. 要有悬念感或情绪触发
4. 参考格式：
   - "🔥XX种[主题]设计，第X种绝了"
   - "闺蜜问我为什么跪着看[主题]"
   - "做[主题]3年，总结出X条避坑指南"

请直接输出10个标题，不要解释。
```

### 爆款文案生成器

```
你是一位小红书爆款文案写手，擅长写高互动、高收藏的笔记。

【粉丝量】：0-1000新号
【内容方向】：小说同人设定定制（斗罗大陆武魂、叶罗丽魔法、神印王座）
【目标】：吸引精准粉丝关注，引导私信约稿
【风格】：口语化、真诚、有温度

写作要求：
1. 开头用"姐妹们/家人们"拉近距离
2. 中间分享真实感受或创作过程
3. 结尾引导互动（如"你喜欢哪个设定？评论区告诉我"）
4. 全文300-500字
5. 适当使用emoji，不要堆砌
6. 加入3-5个相关话题标签

【具体内容】：[在这里描述你要发的内容]
```

【内容】：
