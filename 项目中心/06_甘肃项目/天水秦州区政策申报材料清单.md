## 三、创新型中小企业评价（P1 · 当前窗口）

**对口部门**：天水市工业和信息化局  
**地址**：天水市秦州区春风路政务中心2号楼  
**参考信息**：2026年第二批正在评价中，工信局网站有公示名单

### 3.1 认定条件（需同时满足）

1. 在甘肃省内注册登记、具有独立法人资格，符合《中小企业划型标准规定》
2. 企业未被列入经营异常名录或严重失信主体名单
3. 提供的产品（服务）不属于国家禁止、限制或淘汰类
4. 满足以下四个指标中的至少三项：
    - 科技人员占从业人员比例 ≥ 10%
    - 研发费用占营业收入比例 ≥ 3%
    - 上一年度营业收入 ≥ 300万元（或净资产 ≥ 500万元）
    - 拥有1项以上与主营业务相关的I类知识产权（发明专利、集成电路布图设计等）或2项以上II类知识产权（软著、实用新型、外观设计等）

### 3.2 材料清单

- [ ] 《创新型中小企业自评表》（登录工信部优质中小企业梯度培育平台在线填写打印）
- [ ] 企业营业执照副本复印件
- [ ] 上一年度审计报告或财务报表（须含研发费用明细）
- [ ] 知识产权证明列表及证书复印件（软著登记证书等）
- [ ] 科技人员名单（姓名、学历、岗位、社保缴纳月份）
- [ ] 企业信用报告（信用中国网站下载）
- [ ] 材料真实性声明
- [ ] 其他佐证材料（如科技计划立项证明、获奖证书、体系认证等）

### 3.3 申报途径

登录 [https://zjtx.miit.gov.cn/](https://zjtx.miit.gov.cn/) （工信部优质中小企业梯度培育平台）在线填报，同时将纸质材料报送至秦州区工信局。

## 四、甘肃省科技创新型企业认定（P1 · 年度窗口）

**对口部门**：天水市科学技术局  
**地址**：天水市秦州区春风路政务中心2号楼  
**参考信息**：2026年度申报通知已在科技局网站发布

### 4.1 认定条件

1. 在甘肃省注册成立一年以上，具有独立法人资格
2. 对企业主要产品（服务）发挥核心支持作用的技术属于《国家重点支持的高新技术领域》或与云计算、大数据、人工智能等技术相关的现代服务业
3. 科技人员占从业人员比例 ≥ 8%
4. 研发投入：
    - 上年营收 < 5000万元：研发费用占营收比例 ≥ 4%
    - 上年营收 5000万-2亿元：比例 ≥ 3%
    - 上年营收 > 2亿元：比例 ≥ 2%
5. 近一年高新技术产品（服务）收入占企业同期总收入比例 ≥ 50%
6. 拥有至少1项与核心技术相关的I类知识产权，或 4 项以上II类知识产权
7. 企业无重大安全、质量、环保事故和科研失信行为

### 4.2 材料清单

- [ ] 《甘肃省科技创新型企业认定申请书》
- [ ] 企业营业执照副本复印件
- [ ] 企业上一年度审计报告（含研发费用专项审计或研发费用辅助账）
- [ ] 知识产权证书及相关证明材料
- [ ] 科技人员名单（含学历、专业、工作岗位、社保缴纳证明）
- [ ] 高新技术产品（服务）收入专项说明
- [ ] 研发活动说明材料（立项文档、验收报告等）
- [ ] 产学研合作协议（如有）
- [ ] 企业创新能力评价所需的其他材料（检测报告、用户报告、获奖证书等）
- [ ] 材料真实性承诺书

### 4.3 申报途径

登录甘肃省科技管理信息系统在线填报：[http://kjt.gansu.gov.cn](http://kjt.gansu.gov.cn/)  
纸质材料报送至天水市科技局高新科。

## 五、秦州区级科技支撑计划项目（P2 · 年度窗口）

**对口部门**：天水市秦州区科学技术局  
**参考信息**：秦州区政府网站已在2026年6月公示"拟立区级科技支撑计划项目"，说明年度申报已结束或接近尾声，建议提前准备下一年度申报。

### 5.1 项目类型说明

区级科技支撑计划通常分为：

- **工业类**：适用于软件开发、AI应用、智能制造
- **农业类**：不适用
- **社会发展类**：数字化治理等

你的"慧标软件"项目适合申报**工业类科技支撑计划项目**。

### 5.2 材料清单

- [ ] 《秦州区科技计划项目申请书》
- [ ] 《项目可行性研究报告》或《项目实施方案》
- [ ] 企业营业执照副本复印件
- [ ] 企业上一年度财务报表
- [ ] 项目负责人简历及资质证明
- [ ] 项目团队人员构成说明
- [ ] 项目自筹资金承诺函
- [ ] 知识产权证明（如有）
- [ ] 与项目相关的技术合作协议（如有合作单位）
- [ ] 查新报告（部分年度要求）

### 5.3 申报途径

向秦州区科技局提交纸质材料一式三份，同时报送电子版。  
区科技局通常委托区工信局或政务服务中心受理窗口代收。

## 七、高新技术企业认定（P3 · 长期准备）

这是含金量最高的资质（企业所得税从25%降至15%），但需要企业运营满一年以上，建议从注册首日就开始按条件准备材料。

### 7.1 提前储备的材料

- [ ] 研发费用辅助账（从第一笔研发投入开始规范记账）
- [ ] 知识产权布局规划（软著申请周期 1-3 个月，发明专利 12-24 个月）
- [ ] 科技人员管理制度（劳动合同、社保、薪酬标准）
- [ ] 研发项目立项文件（每个研发项目都有正式立项书）
- [ ] 高新技术产品收入证明材料（销售合同、发票、产品说明）

## 八、创业就业类补贴（按需申请）

**对口部门**：天水市人力资源和社会保障局

### 8.1 重点关注的补贴

|补贴类型|条件|标准|材料|
|---|---|---|---|
|一次性创业补贴|毕业5年内高校毕业生/返乡农民工首次创业，正常经营1年以上|一般5000-10000元|身份证明、营业执照、经营流水、场地证明|
|社保补贴|招用就业困难人员或小微企业招用应届毕业生|按企业缴纳部分的一定比例返还|劳动合同、社保缴费明细、人员身份证明|
|就业见习补贴|认定为就业见习基地，吸纳毕业2年内高校毕业生见习|每人每月补贴当地最低工资标准的一定比例|见习协议、考勤记录、见习人员毕业证|

### 8.2 申报途径

秦州区人社局就业服务中心窗口咨询办理。

## 十、准备工作建议

1. **知识产权先行**：软件企业的软著登记周期约1-3个月，建议立即开始申请"慧标软件"的软著登记（中国版权保护中心），这是多项申报的硬门槛。
    
2. **财务规范**：从第一笔支出开始建立规范的财务账目，尤其是研发费用独立核算。可以考虑使用天水本地的代账服务降低成本。
    
3. **对接联系人**：
    
    - 秦州区工信局（创新型中小企业）：建议直接到政务中心2号楼当面咨询
    - 天水市科技局高新科（科技创新型企业认定）：电话咨询当前批次截止时间
    - 秦州区人社局就业科（创业补贴）：确认一次性创业补贴的具体标准
4. **打印/装订**：以上多数材料需一式三份胶装提交，秦州区政务中心附近通常有文印店可代办。
