# 01 记忆体系

## 记忆存储结构

| 层 | 位置 | 说明 |
|---|---|---|
| 常驻记忆 | `~/.hermes/memories/MEMORY.md` + `USER.md` | 每轮注入，2,200 / 1,375 字符上限 |
| git 版本控制 | `~/.hermes/memories/`（git 仓库） | 每日 23:30 自动快照，可回滚/查历史 |
| 向量深度记忆 | `~/.hermes/mcp-memory/memory.db` + fact_store | 79 事实，实体解析+信任分 |
| 压缩维护 | `~/.hermes/scripts/memory-*.py` | 归档/压缩/主题汇总/Obsidian 同步 |

## 记忆 git 版本控制（MemFS 思路，2026-09-12 落地）

- 仓库：`~/.hermes/memories/`（main 分支，2 提交：c18efeb 基线、bbe9b14 忽略 *.lock）
- 快照脚本：`~/.hermes/scripts/memory-git-autocommit.sh`（cron 每日 23:30 静默执行，job 51922881b472）
- 用法：
  - 查历史：`cd ~/.hermes/memories && git log --oneline`
  - 回滚：`git checkout <commit> -- MEMORY.md USER.md`
- **安全**：只存本地，不推 GitHub（敏感信息）

## 记忆质量审计（/doctor 思路，2026-09-12 落地）

```bash
python3 ~/.hermes/scripts/memory-audit.py
```

检测四类问题（**只报告不修改**，人工过滤后决定清理）：
1. ⏰ 过期 — 含过去日期且带"到期/续费/有效期"等时效词
2. 🔁 重复 — 最长公共子串含信息量（≥4汉字或数字+汉字）
3. ⚔️ 冲突 — 实体+数字（支持"实体:数字"与"实体数字"双格式，实体归一化去修饰词）
4. 📏 超长 — 单条 >200 字符

已验证：自测假数据全抓（2重复+2冲突+1过期+1超长）；真实记忆零误报（30+21 条健康）。

## 记忆写入原则

- 优先级：用户偏好 > 环境事实 > 流程（流程进技能，不进记忆）
- 写入为陈述句事实（"用户偏好 X"），不是命令（"必须 X"）
- 过时信息：replace/remove 更新，不堆叠
- 不存任务进度/完成日志（用 session_search 召回）
