# 02 技能体系

## 存储与结构

- 位置：`~/.hermes/skills/`（文件系统）——**改文件即全局生效**，所有入口共享
- 总量：431 个 SKILL.md，80+ 分类目录
- 单技能结构：`SKILL.md`（YAML frontmatter: name/description + 正文）+ 可选 `references/` `templates/` `scripts/` `assets/`
- 跨 profile：`~/.hermes/profiles/<name>/skills/`（默认 profile 用主目录）

## 管理命令

| 操作 | 工具 | 说明 |
|---|---|---|
| 加载 | `skill_view(name)` | 用前必读，含 linked_files |
| 创建 | `skill_manage(action=create)` | 复杂任务成功（5+ 调用）后沉淀 |
| 修补 | `skill_manage(action=patch)` | 发现过时/缺步骤/有坑立即修 |
| 重写 | `skill_manage(action=edit)` | 大改版 |
| 删除 | `skill_manage(action=delete)` | 合并进伞技能（absorbed_into）或清理 |
| 辅助文件 | `write_file/remove_file` | 只允许在 references/templates/scripts/assets/ |

## 升级与同步机制

1. 技能是文件 → 修改/新增后**所有入口（8648/8748/桌面端）新会话自动加载最新版**
2. 老会话有启动快照，需新会话/刷新
3. 技能与记忆的分工：流程/步骤/命令 → 技能；偏好/事实/环境 → 记忆
4. 技能包导出：可打包成公开技能包（EPC 技能包先例：5 技能已脱敏未发布，发布=GitHub 公开库）

## 维护纪律

- 用了技能发现坑 → 当场 patch（不等老板要求）
- 完成复杂任务（5+ 调用、踩过坑）→ 主动提议存技能
- 剪枝后（[SKILL_PRUNED]）→ 使用前必须重载 skill_view
