## 工具一：Codex 15 个必装技能 —— 给 AI 装上“插件”，让编程效率翻倍

**一句话总结**：Codex 技能机制让 AI 从“聪明的实习生”变成“带工具箱的老手”，15 个高频技能覆盖规划、调试、CI 修复、去 AI 味等全流程。

**核心用法**：
- **先装三件套**：`skill-creator`（造技能）、`skill-installer`（装技能）、`plugin-creator`（打包分享），随 Codex 自动安装，无需下载。
- **开发流程八件套**：`create-plan` 强制先出计划再写代码；`grill-me` 让 AI 反向拷问需求细节；`gh-fix-ci` 一键排查修复 GitHub Actions 失败；`stop-slop` 专治 README 和提交信息里的“AI 腔”（delve、leverage、此外、值得注意的是……）。
- **两个硬核补充**：`book-to-skill` 把 PDF 书拆成结构化技能，按需加载章节，token 消耗仅为直接喂全书的 1/24～1/51；浏览器技能把网页操作接进 Codex。

**社区反馈**：文章发布即收获大量收藏与转发，开发者实测“装上技能后，AI 不再上来就猛写、写完发现方向错了”，`gh-fix-ci` 和 `stop-slop` 被称为“周五下班前的救命稻草”。

## 工具二：lark-channel-bridge —— 把 Claude Code 装进飞书，手机上随时当“AI 工作助理”

**一句话总结**：一条命令 `npx -y lark-channel-bridge@latest start`，把本地 Claude Code 变成飞书机器人，手机端即可随时对话、查看生成的图片文件、点击交互卡片操作。

**核心用法**：
- 安装后，飞书消息自动转给 Claude Code 处理，真正实现“AI 工作助理”随身带。
- 飞书原生支持可交互卡片，渲染效果比终端好，按钮点击替代繁琐打字。
- AI 生成的图片、文件直接在对话里显示，无需跳转链接。
- 聊天记录全量搜索，配合 Claude Code 上下文压缩，历史对话随时可查。

**社区反馈**：向阳乔木（@vista8）实测推荐，171 赞、21 转发、40 条回复，体验过的开发者评价“零差评、强烈推荐”，特别适合需要随时随地处理代码任务的移动办公场景。

## 工具三：Aibijia（爱比价） —— AI 订阅一键比价，帮你找最便宜的 Token

**一句话总结**：聚合 ChatGPT、Claude、Gemini、Grok 等主流 AI 服务的官方订阅价与卡网渠道报价，一眼看清哪个地区、哪个渠道最划算，省下的钱够买几杯咖啡。

**核心用法**：
- 打开 aibijia.org，选模型、选套餐，自动加载官方价与各平台报价。
- 支持 ChatGPT Plus/Pro/Team、Claude Pro/Max、Gemini Pro/Ultra、Grok 等全系列对比。
- 还能看官方订阅在不同地区的价格差（如菲区 ChatGPT Pro 20x 折合人民币约 1100 元，拼车分摊更低）。
- 内置避坑曝光与镜像站导航，买前先查一查，防踩雷。

**社区反馈**：鱼总聊AI（@AI_Jasonyu）的“129 个值得关注博主大合集”里收录，向阳乔木（@vista8）也曾推荐“每周时间有限但想获取前沿信息”的三个精选信息源之一，开发者圈子口碑好，实测“比自己去各群问价格靠谱太多”。
