# EPC Cost & Profit Control (成本利润管控)

Use this skill when an EPC project is about to start or is under construction, and the contractor needs a cost-profit control system: budget decomposition, target-profit setting, cost-driver analysis, and a weekly Excel cockpit that links progress with cost and raises early warnings.

## When to Use

- 明天开工,今天做成本管控体系
- 需要把预算价→合同价→目标成本→目标利润的链路算清楚
- 需要每周跟踪成本偏差、利润预测、进度-成本剪刀差
- 固定单价合同、需垫资施工、有目标利润率要求(如25%)

## Prerequisites

- 造价分析表(.xls 旧格式,用 xlrd 读取)
- 清单计价表(.xlsx,用 openpyxl 读取)
- 合同文本(.doc/.docx)
- Python 3 + xlrd + openpyxl + openpyxl

## Core Principles

1. **不做理论制度,做每周10分钟能填完、三分钟能看完的Excel驾驶舱**
2. **预算中的"利润"是定额利润**(行业取费标准规定,通常1-2%),不是真实利润。实际利润全靠成本控制跑出来
3. **每个分项的目标成本不能直接用"预算价×目标成本率"**,必须考虑合同优惠比例
4. **四大成本抓手**:主材(35-40%)、劳务(10-15%)、措施费(7-8%)、管理费(3-4%)

## Procedure

### Step 1: 提取造价数据

```bash
pip3 install xlrd openpyxl
```

.xls 造价分析文件(用 xlrd):
```python
import xlrd
wb = xlrd.open_workbook(path)
ws = wb.sheet_by_name('项目造价分析')
# 列: 0=序号 1=编码 2=名称 3=总价 4=建筑工程 5=安装工程
#     6=人工费 7=材料费 8=机械费 10=主材费 11=实体项目合计
#     20=措施项目合计 21=企业管理费 22=利润(定额) 24=税金
# 注意:列索引因项目而异,读取前先打印几行样例确认
```

⚠️ 预算中的"利润"列(通常1-2%)是定额计价规定的法定利润提取,不是真实利润。即使预算利润列显示亏损,不影响目标利润率的设定。

### Step 2: 建立成本利润模型

```
预算总价(从造价分析提取)
合同优惠比例 = 合同价 / 预算价
目标利润 = 合同价 × 目标利润率(如25%)
目标成本上限 = 合同价 - 目标利润
需节省金额 = 预算总成本 - 目标成本上限
```

每个分项的目标成本(考虑优惠比例):
```python
discount_ratio = 合同价 / 预算价          # 如 940/965 = 0.9741
cost_ratio = discount_ratio * 目标成本率   # 如 0.9741 × 0.75 = 0.7306
分项目标成本 = 分项预算价 × cost_ratio
```

验证:所有分项目标成本之和 ≈ 合同价 × 目标成本率(偏差应在±1%以内)

### Step 3: 四大成本控制抓手(每次必分析)

**抓手一:主材费(预算占比最大,35-40%)**
- 钢材(特别是钢结构,常是最大单品)、商品混凝土、墙面/屋面材料
- 控制手段:进场过磅点验、按图算量对比预算量、超量预警

**抓手二:劳务成本(10-15%)**
- 重点关注工效(每人每天产出)
- 日报表记录出勤人数
- 每周计算单位工效 vs 行业基准
- 预警信号:进度50%但人工费花了60%

**抓手三:措施项目费(7-8%)**
- 安全文明施工费(硬性支出,不可省)
- 模板支架/脚手架(可优化)
- 钢结构安装方案选择直接影响措施费

**抓手四:管理费(3-4%)**
- 项目部日常开支、差旅、招待
- 严控非生产性支出

### Step 4: 成本驾驶舱表设计(Excel)

每周更新的核心驾驶舱 = 预算分解表 + 实际支出 + 进度联动:

| 分项 | 预算金额 | 目标成本(预算×折扣) | 已支出 | 进度% | 按进度应支出 | 偏差 | 预警 |
|------|---------|-------------------|--------|-------|------------|------|------|
| 办公楼土建 | xx万 | xx万 | xx万 | xx% | xx万 | ±xx | 🟢/🟡/🔴 |

预警规则:
- 🟢 正常:偏差 < 3%
- 🟡 关注:偏差 3-5%,或进度-成本剪刀差出现
- 🔴 报警:偏差 > 5%,或"进度60%但钱花了70%"

核心监控指标(每周必看):
- `成本偏差 = 已支出 - (预算支出 × 进度比)`
- `利润预测 = 合同结算收入 - (已支出 + 剩余预计成本)`
- `剪刀差 = 成本完成率 - 进度完成率`(正值=超支,>5%报警)

### Step 5: 材料市场价格对比(独立工作流)

用户发来今日材料价格(如"钢筋12-3390")时:
1. 定位预算基准价:从成本驾驶舱【材料成本明细】找"预算单价"列
2. 做对比表:规格、今日价、预算价、差额、幅度(%)五列
3. 用预算用量 × (预算单价 - 今日价) 估算整体节省
4. 出采购建议:判断当前价格水平,给"建议锁价/观望"
5. 注意:预算定额价通常偏高(如钢筋4,500元/吨 vs 市场3,400-3,500),低26-28%是正常市场波动

### Step 6: 横道图与成本联动

- 每项任务的计划时间 → 对应成本支出计划
- 横道图调整 → 必须同步调整成本计划
- 每周例会:横道图进度 vs 成本支出,交叉验证

### Step 7: 每周成本复盘简报

```
# XX项目 第X周成本复盘 (日期范围)

## 本周数据
- 累计完成产值:xxx万 (进度xx%)
- 累计已支出:xxx万

- 分项A:偏差+xx%,原因分析

```

## 外单位报价 vs 清包成本对比分析

用户发来第三方报价单问"合不合理、自己干省多少"时:

**第一步:拆口径** — 外单位报价 vs 自建成本通常口径不同:
- 外单位含管理费+利润(通常10-15%)+税金(9%一般纳税人)
- 自建只算人工+材料(清包),不含利润

**第二步:调到同一口径**:
- 外单位含税9% vs 自建不含税 → 外单位÷1.09再比
- 外单位管理费利润15% → 外单位×0.85约等于直接成本

**第三步:逐项核验**:
- 总报价 = 分项之和?自己算一遍,不要只看用户写的数字
- 面积口径是否一致(建筑面积 vs 滴水投影面积,差10%造价就差10%)
- 单价合理性(对照当地市场行情)

**第四步:出判断意见**:数字核验结论、单价合理性、口径差异说明、核心风险提示、建议(能不能自己干/怎么砍价)

**典型陷阱:**
- 用户说"节约约6万"但实际差额是35万 — 用户可能只算了某一部分的对比,自己全口径算一遍
- 自建的管理费没算进去 — 自己公司项目管理人员的工资、差旅一样要摊

## Pitfalls

1. **.xls vs .xlsx** — 造价分析文件经常是旧格式 .xls,必须用 xlrd;清单文件 .xlsx 用 openpyxl
2. **预算中的"利润"是定额利润**(1-2%),不是真实利润
3. **固定单价合同** — 工程量按实结算,"省钱"是提高工效、降低损耗、优化采购,不是偷工减料
4. **垫资风险** — 平衡付款节点和支出节奏,避免现金流断裂。签约预付款/进度款时间点要卡紧
5. **劳务工效是关键变量** — 出勤人数≠有效产出
6. **变更签证要及时签认** — 施工中洽商变更不要等竣工再补,变更也是利润来源之一
7. **合同优惠比例要在分项中按比例分摊** — 预算价和合同价的差价,成本分解时不能只压某一个分项
8. **读取 Excel 用 data_only=True** — 否则读到公式字符串
