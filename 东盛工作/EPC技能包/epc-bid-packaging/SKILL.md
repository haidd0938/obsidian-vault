# EPC Bid Qualification Packaging (报名资料编制)

Use this skill when a user sends a government / SOE / city-investment / affordable-housing recruitment announcement for decoration or renovation work, and needs to register as a candidate: interpret the announcement, position company strengths, design tiered pricing, and produce the complete qualification package (company profile + pricing plan + track records + commitment letters + credit statement) as a single editable Word document.

## When to Use

- 用户发来政府/国企/城投/保障房公司的装修服务合作单位招募公告
- 需要以施工方/装修公司身份报名,编制全套资格预审/报名资料
- 涉及"过渡费抵装修款""工抵房"等创新结算模式
- 需要出分档装修报价方案、承诺函、业绩证明等成套文件

## Prerequisites

- 用户提供:招募公告原文(文字/PDF)、公司资质文件(营业执照/资质证书/安许证)、真实业绩数据、合作品牌清单
- Python 3 + python-docx(用于生成 Word 交付物)
- 不要编造工期、业绩、品牌——所有数字必须来自用户确认

## Core Principles

1. **读懂公告意图是第一步** — 公告每一条要求背后都有对应的评审权重,它不是罗列,是打分表
2. **公司优势要翻译成"对方的需求语言"** — 不说"我们有二级资质",说"设计+施工一体化,降低多方协调成本"
3. **分档报价要有策略** — 通常三档:底价(招标门槛价)、主力(走量利润款)、品质(拉开档次)
4. **创新模式(抵款/代付/分期)要专门回应** — 公告如果提出特殊结算模式,必须有单独的承诺函
5. **资料不是越多越好** — 匹配公告各项要求逐项对应,不堆砌无关资质
6. **甲方给的文件是模板,填空不修改条款** — 政府/国企的承诺书/协议模板,公司信息填进去即可,条款不要改;有异议的内容单独写说明附后
7. **报名后务必当面沟通一次** — 公告写的和甲方实际说的交易结构可能有差异,当面聊才能拿到真实条款

## Procedure

### Step 1: 公告深度解读

提取关键评审维度并推断权重:

| 评审维度 | 公告中对应表述 | 隐含权重 | 应对策略 |
|---------|--------------|:-------:|---------|
| 资质合规 | 主体资质、经营状态、安全许可 | 高(门槛项) | 资质证书原件扫描+联网可查 |
| 质量管控 | 工程质量标准、材料环保防火 | 高(淘汰项) | 材料品牌清单+检测报告承诺 |
| 施工保障 | 固定团队、按期交付、质保售后 | 高(评分项) | 施工组织方案+工期承诺+质保书 |
| 报价竞争力 | 价格公允、分档报价 | 中高 | 梯度定价+批量优惠 |
| 创新模式配合度 | 抵款结算、对账配合 | 中(特殊要求) | 单独出具抵款配合承诺函 |
| 企业信誉 | 无事故、无失信、无处罚 | 中(一票否决) | 征信承诺函+信用查询截图 |

公告意图识别技巧:
- "公开透明、择优遴选、平等合作、合规履约" → 评审过程要正规
- "安置户满意、公司减负、合作方共赢" → 三方利益都要说到
- "过渡费抵装修款" → 核心模式创新点,必须重点回应
- "择优遴选" → 虽是招募但实质是竞争性谈判

### Step 2: 企业优势定位

找差异化点,不堆叠实力:

| 公司类型 | 可能的差异化优势 | 话术示例 |
|---------|----------------|---------|
| 设计+施工双资质 | 一体化服务减少协调 | "设计施工一体化,避免设计画得出来施工做不出来" |
| 本地企业 | 响应快、成本低、熟悉规范 | "深耕本地多年,对安置房标准、验收规范极为熟悉" |
| 资金实力强 | 批量承接、垫资能力 | "注册资本XXXX万元,具备批量装修垫资能力" |
| 有同类业绩 | 经验最匹配 | "近三年完成XX安置房批量装修XX套,经验可复制" |

### Step 3: 分档报价策略

标准三档结构(参考区间,单价需按当地市场核实):

| 档位 | 定位 | 配置要点 |
|:----:|------|---------|
| A档 | 投标保底/低价入门 | 强化地板+普通墙地砖+基础橱柜+简装卫浴 |
| B档 | 主力利润款/走量 | 品牌地板+品牌墙地砖+品牌橱柜+品牌洁具 |
| C档 | 品质标杆/拉开档次 | 高端品牌主材+造型吊顶+升级卫浴+个性设计 |

报价策略要点:
- B档和C档差价不宜过大(200-300元/㎡为宜),避免中间档被跳过
- 每档主材品牌要可查可验证,防止甲方质疑"挂羊头卖狗肉"
- 批量优惠条款(如50套以上3%、100套以上5%)增加竞争力
- 创新结算模式不涨价承诺 — 关键表态,打消甲方顾虑

### Step 4: 报名文件结构(单文件 Word 交付)

最终交付物必须是**一个完整的 Word 文档(.docx)**,不是一堆 md。结构:

```
封面页(项目名称+报名单位+资质等级+日期)
目录页(带页码)
第一章 企业简介及综合实力说明
  ├── 一、公司概况(企业信息表)
  ├── 二、资质优势(列出所有资质+差异化说明)
  │   ├── 2.1 营业执照(占位页)
  │   ├── 2.2 资质(占位页)
  │   └── 2.3 安全生产许可证(占位页)
  ├── 三、核心能力
  ├── 四、管理团队(4层级:核心层/质量管控层/施工作业层/后勤保障层)
  ├── 五、施工管理体系(流程/质量/工期/售后)
  └── 六、合作优势总结(表格)
第二章 近三年装修业绩案例(真实数据表+合同复印件页)
第三章 分档装修报价方案及报价清单(三档总表+材料品牌说明)
第四章 创新结算模式配合承诺函(抵款模式确认+配合承诺+价格承诺+结算周期)
第五章 施工工期及质保服务承诺书(工期/质量/售后/安全文明/满意度)
第六章 企业征信及无违法违规承诺函
```

内容要求:
1. 公司信息要完整(统一社会信用代码、注册地址、法定代表人、成立时间、注册资本、开户行、经营范围)
2. 业绩用真实数据,不写"案例说明"
3. 工期要核实后写,不套模板
4. 甲方名称一字不差
5. 材料品牌写实际合作的,不写通用名
6. 抵款承诺要写"有限度" — 加抵扣上限(如"抵扣上限为10%")
7. 管理团队分4个层级,不虚

承诺函核心要素(以抵款配合为例):
1. 明确接受 — "我公司充分理解并完全接受'过渡费抵装修款'结算模式"
2. 价格不变 — "抵款结算单价与现金结算单价完全一致,不因抵款模式调价"
3. 配合措施 — 对账配合、票据合规、节点清晰
4. 有限度接受 — 加上抵扣上限,显示专业而不鲁莽

### Step 5: Word 文档生成

```bash
pip3 install python-docx
python3.12 /tmp/gen.py   # 用 python3.12 执行(系统 python3 可能没有 python-docx)
```

关键代码备忘:
```python
from docx import Document
from docx.shared import Pt, Cm
from docx.oxml.ns import qn

# 设置中文字体(必须同时设 eastAsia,否则乱码)
run.font.name = '宋体'
run.element.rPr.rFonts.set(qn('w:eastAsia'), '宋体')

# 政府文档标准页边距
section.top_margin = Cm(2.54)
section.bottom_margin = Cm(2.54)
section.left_margin = Cm(3.17)
section.right_margin = Cm(3.17)

# 行距 1.5
style.paragraph_format.line_spacing = 1.5
```

不要用 `execute_code` 沙盒生成 docx(沙盒没有 python-docx),用 terminal 执行。

## Pitfalls

1. **不要只美不真** — 政府类招募看真实材料(合同/资质/证书),关键文件要盖章扫描、合同要附复印件
2. **提交时间即截止时间** — 公告写的截止日=最终节点。当天截止就先发邮件再补纸质
3. **竞争力在"匹配度"** — 不是"我公司多牛",是"我公司正好符合你们的需求"
4. **创新结算模式必须单独回应** — 公告提到了却没回应,大概率被筛掉
5. **发完邮件一定要打电话确认** — 公告里的联系人电话是用来打通关系的,不是摆设
6. **不要遗漏签字盖章环节** — 承诺函末尾留"法定代表人/授权代表签字:______"和盖章位
7. **第一次就直接出 docx** — 用户拿到一堆 md 会说"给我一个 word 版"(必然发生)
8. **工期和报价必须向用户确认** — 不要编标准工期,实际工期可能完全不一样
9. **材料品牌写用户真实合作的** — 不写你猜的品牌
10. **承诺要有限度** — 抵款不要写无限接受,写上限,显示专业诚信
