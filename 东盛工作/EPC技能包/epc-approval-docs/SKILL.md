# EPC Government Approval Documents (报建审批公文)

Use this skill when a construction project needs pre-construction government approvals: applications for land use planning permits, building (engineering) planning permits, project filing/registration (备案), exemption applications, or official response letters (红头文件 conventions).

## When to Use

- 建设用地规划许可证申请
- 建设工程规划许可证申请
- 项目备案/立项申报(直接发包备案、人防报建等)
- 减免申请、承诺书、情况说明等配套公文
- 任何需要按中国公文规范写给政府部门/业主单位的正式文件

## Core Principles

1. **引用政策前必须联网核实** — 文件名、文号、原文条款一字不差。引用错误文号是公文大忌(曾有把"纳入政府性基金管理"写错的案例)
2. **格式按公文规范** — 文头+签发人+主送+引据→事项→指标→附件+落款
3. **数据要来自项目真实资料** — 面积、地址、金额等以审批部门认可的为准,备案证/规划证信息冲突时以规划审批为准
4. **引据要分层** — 先引上位法/政策,再引地方规定,最后引项目实际情况
5. **编号命名** — 报建文件按顺序编号(00封面、01立项、02规划、03用地……)

## Procedure

### Step 1: 确认项目基础数据

从用户处收集(必须核实,不编造):
- 项目名称、建设单位全称(与营业执照一致)
- 建设地点(以规划审批/备案的地址为准)
- 建筑面积、用地面积、建设内容
- 投资额、资金来源
- 相关批文编号(立项批复、用地预审、环评等)

⚠️ 常见冲突:备案证面积 vs 规划审批面积不一致 → 以规划审批为准,并在文中说明依据。

### Step 2: 联网核实引用政策

写进公文的每个政策依据都要核实:
```bash
# 搜索确认文件名、文号、条款原文
web_search("文件名 文号 原文")
```

必须核实的要素:
- 文件全称(含发布机关全称)
- 文号(如"甘财税法〔2017〕40号")
- 具体条款号+原文表述
- 是否仍然有效(有无废止/替代文件)

### Step 3: 按公文结构起草

标准结构(红头文件规范):

```
[文头:发文机关+文号,如"XX公司发〔2026〕XX号"]
关于XXX的申请(标题,居中,二号宋体加粗)

[主送单位:顶格]

[引据]根据《XXX》(文号)第X条之规定,以及XX项目立项批复(文号)的要求,……

[事项]我公司拟在XX地点建设XX项目,总建筑面积XX㎡,……

[指标]项目总投资XX万元,其中……主要建设内容……计划工期……

[请求]特申请办理XXX,恳请贵局审核批准。

[附件]
附件1:XXX
附件2:XXX

[落款]
XX公司(盖章)
2026年X月X日
```

格式要点:
- 标题:发文机关+事由+文种,如《关于办理建设工程规划许可的申请》
- 主送单位:顶格写,如"天水市自然资源局:"
- 正文:引据→事项→指标→请求,逻辑递进
- 落款:单位全称+日期,盖章
- 公文字体:A4,标题二号宋体,正文三号仿宋,行距28磅(如平台要求)

### Step 4: 常见报建公文模板

**建设用地规划许可申请:**
- 引据:《城乡规划法》第X条
- 内容:用地位置、面积、用途、四至范围
- 附件:立项批复、用地红线图、规划条件

**建设工程规划许可申请:**
- 引据:《城乡规划法》第X条+规划条件
- 内容:建设规模(总建筑面积)、建筑高度、层数、容积率
- 附件:设计方案、总平面图、用地规划许可

**项目备案/立项申报:**
- 内容:项目名称、建设性质、建设地点、建设内容及规模、总投资、资金来源、开竣工时间
- 附件:营业执照、土地权属证明、环评意见(如需)

### Step 5: 交付 Word

- 直接交付可编辑 .docx(不是 md)
- 编号命名:00封面、01立项、02规划、03用地……
- 页面:A4,标准页边距,中文字体设置(宋体/仿宋)
- 预留盖章位和签字栏

## Pitfalls

1. **引用政策必须联网核实** — 不要凭记忆写文号和条款,官方名称一字都不能差
2. **面积/地址/金额要核实** — 备案证与规划审批冲突时,以规划审批为准
3. **不要改政府模板条款** — 甲方/政府给的申请表和承诺书,填空不修改
4. **注意政策时效** — 引用前确认文件是否仍然有效
5. **申报材料编号规范** — 按顺序编号,缺号会让人怀疑材料不全
6. **主送单位不能写错** — 规划许可是自然资源/规划部门,备案是发改委/住建部门,减免是税务/财政,写错等于石沉大海
7. **承诺事项要留余地** — 承诺函中的期限、金额要写可兑现的,别为过审拍脑袋
