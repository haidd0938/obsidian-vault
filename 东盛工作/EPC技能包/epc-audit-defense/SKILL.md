# EPC Audit Deduction Defense (审计核减应对)

Use this skill when an audit department (client's internal or third-party) has deducted amounts from a submitted settlement, and the contractor needs to object item-by-item with evidence, write a formal objection letter, and negotiate to a reasonable recovery ratio.

## When to Use

- 用户发来"审计结果""审计报告""审减""审计核减"等文件
- 用户说"审计结果不理想""审减太多了""审计太狠了"
- 用户提供我方报审价 vs 审计核定价的对比表

## Core Principles

1. **审计不是终局** — 审计结果是核减意见,不是判决书。你有权对每一项核减提出书面异议和证据支持
2. **分项驳斥,不搞总价辩论** — 不要总价层面扯"为什么审这么多",逐项拿出证据反驳
3. **证据为王** — 现场照片、甲方签字确认单、微信记录、会议纪要——哪怕最原始的签字白条,都是法律意义上的证据
4. **审计惯用手法要识破** — "定额套低""工程量缩水""单价打折""以合同包干为由一刀切砍新增"
5. **留出谈判弹性** — 有些项硬顶、有些项让步,目标不是100%守住,而是争取可接受的比例(通常守住70-80%就是胜利)

## Procedure

### Step 1: 整理对比表

三栏对比表(我方报审 vs 审计核定 vs 差额)是数据基础:

| 分项 | 我方报审价 | 审计核定 | 核减额 | 核减率 | 反击可行性 |
|------|-----------|---------|-------|-------|-----------|
| ① 主体工程 | xxx | xxx | -xxx | xx% | ⭐⭐⭐ |
| ② 新增项目 | xxx | xxx | -xxx | xx% | ⭐⭐⭐⭐ |
| ③ 临时设施 | xxx | xxx | -xxx | xx% | ⭐ |
| **合计** | **报审总价** | **核定价** | **核减总额** | **核减率** | — |

反击可行性评级:
- ⭐⭐⭐⭐ = 有充分现场证据/甲方确认,反击成功率极高
- ⭐⭐⭐ = 有证据但审计方可能有理论依据,需据理力争
- ⭐⭐ = 部分合理核减,可适当让步
- ⭐ = 弹性项,优先让步用来做谈判筹码

### Step 2: 识别审计核减手法

| 审计手法 | 表现 | 反击策略 |
|---------|------|---------|
| **包干价一刀切** | "合同包干价xxx,超过部分不认" | 拿出合同条款"视施工情况现场确定"——包干≠没有变更,新增内容按实结算有合同依据 |
| **工程量核减** | 围墙长度/面积/方量被砍 | 拉现场实测数据、照片、甲方施工员签字确认单。现场施工跟图纸有出入很正常,甲方确认了就认 |
| **单价打折** | 定额套低,材料价砍到信息价以下 | 提供实际采购发票、收据、合同。大宗材料有发票就硬顶,零星采购用市场询价佐证 |
| **新增项目不认** | "合同外内容没有书面确认" | 即使没有正式签证,找甲方现场确认记录(微信聊天、会议纪要、施工日志签字)。口头承诺+实际施工+甲方知情=事实合同 |
| **临时设施费用砍** | "临设费含在管理费里了" | 临时设施是实体投入(铁皮围挡、形象墙、展板),有实物照片+材料采购凭证 |
| **"无甲方签字"** | 所有没有甲方签字的小项全部砍 | 逐项准备替代证据(微信沟通记录、施工日志、现场照片上有甲方人员入镜) |
| **打折法** | 不逐个争论,直接总价打8折/9折 | 逐项展开,不让审计打统仗 |

### Step 3: 编制《审计核减异议函》

```
标题:关于[项目名称]审计结果的异议函

致:[甲方/审计单位名称]

一、异议事项概述
  我方报送结算金额 xxx 元,贵方审计核定 xxx 元,核减 xxx 元(核减率 xx%)。
  经逐项复核,我方对以下核减事项持有异议:

二、逐项异议及依据
第1项:[分项名称]
  我方报送:xx元  审计核定:xx元  核减:xx元
  异议理由:
  ① [事实陈述,如"实际完成工程量xxx,有xxx签字确认单"]
  ② [合同依据,如"合同第x条约定..."]
  ③ [证据清单:附件1—现场照片、附件2—材料发票...]
  要求:维持报送价xx元

三、无异议项目
  [列出同意核减的部分,体现理性态度]

四、协商请求
  请求贵方重新核定上述异议项目,如有必要可组织现场复核。
  我方保留在协商不成时依法申请工程造价鉴定的权利。

落款:[施工单位名称、日期、联系人]
附件清单:附件1/附件2/附件3...
```

### Step 4: 谈判策略决策树

```
审计核定金额 vs 我方心理底线
├── 核减率 ≤ 10%:可以接受,出异议函意思一下
├── 核减率 10%~20%:主力异议项硬顶(新增项目+有证据项),临时设施可让步
├── 核减率 20%~30%:逐项争议,出正式异议函,准备现场取证
│   └── 弹性项让步5%~10%,主力项守住70%+目标
└── 核减率 ≥30%:全面异议,考虑工程造价鉴定
    └── 先走协商,协商不成书面要求第三方鉴定
    └── 评估诉讼成本与收益(标的额 vs 律师费)
```

### Step 5: 取证清单(按优先级)

1. **甲方人员签字确认单** — 最强证据,任何形式的签字白条都有效
2. **微信聊天记录** — 截图+录屏,展示甲方知晓并同意施工内容(截全图:昵称/头像/时间线)
3. **现场施工照片** — 拍摄时间、内容清晰,最好有甲方人员在照片中
4. **材料采购凭证** — 发票、收据、转账记录、送货单
5. **施工日志/会议纪要** — 记录施工过程并签字的日志本
6. **通话录音** — 部分地方法院认可私自录音在工程纠纷中作为证据(不侵犯合法权益+不违反法律禁止性规定,需核实当地规定)

### Step 6: 争议升级路径

```
友好协商(出异议函+当面谈)
  → 第三方调解(造价协会/建筑业协会)
  → 工程造价司法鉴定(法院委托有资质机构,费用通常按标的额1%-3%)
  → 诉讼/仲裁(最后手段,评估标的额 vs 诉讼费+律师费)
```

## 话术模板

- 新增项目: "这部分是合同签订时未预见、施工过程中应甲方现场要求增加的内容,甲方XXX(姓名)在场确认并同意施工。虽然没有正式变更签证,但已经有事实履行+甲方知情+我方投入,事实合同成立"
- 工程量核减: "审计依据的设计图纸在施工中有调整,现场实际尺寸与图纸不一致是工程常态。我方的工程量有现场施工记录+甲方施工员XXX签字确认,应以此为准"
- 临时设施: "临时设施是看得见摸得着的实物投入——铁皮围挡、形象墙、大门、展板,都有照片和采购凭证,不能跟'临时设施费'的管理费概念混为一谈"

## Pitfalls

1. **不要一上来就全盘否定审计** — 先表示"接受部分合理核减"再逐项异议,更有说服力
2. **不要情绪化** — 数据+事实+法律依据是最好的谈判工具
3. **审计文件和结算文件要分开读** — 审计方可能直接在结算书上批注砍价,也可能出独立报告
4. **微信记录要截全图** — 包含昵称、头像、时间线,否则审计说"不知道谁发的"
5. **注意审计时效** — 有些合同约定审计异议期(如收到审计结果后15天),超期默认接受
6. **内部审计 vs 第三方审计策略不同** — 内部审计看重"态度好、数据清";第三方审计按行业标准逐条核对,需规范证据
7. **审计核减与质保金无关** — 核减的是结算价,质保金按最终结算价的5%留,互不影响
8. **诉讼性价比评估** — 核减额在10万元以下时,诉讼性价比往往不高,优先协商
