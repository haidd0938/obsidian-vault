# 咸阳电梯井道围护及装饰工程报价方案

**项目名称：** 水电十五局19-3建筑电梯井道围护及装饰工程
**项目地点：** 陕西省咸阳市
**工程概况：** 6层住宅楼，钢结构预留电梯井道，1台电梯
**井道尺寸：** 2100×2100mm，总高19.2m，底坑深1.6m
**我方施工内容：** 电梯井道围护结构及全部装饰工程（电梯主材及安装由厂家负责）
**钢结构主体：** 我方自行施工
