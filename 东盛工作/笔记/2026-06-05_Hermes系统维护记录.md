# 2026-06-05 Hermes 系统维护记录

## 背景
macOS 系统升级后，Hermes Web UI (`http://localhost:8648`) 无法访问。

## 排查过程

### 问题1：Web UI 无法启动
- `http://localhost:8648` 连接被拒绝
- gateway (OpenClaw 18789) 正常运行
- 发现 SQLite schema 迁移失败：`Cannot add a NOT NULL column with default value NULL`
- **根因**：`updated_at INTEGER NOT NULL` 列加到已有表时没设 DEFAULT，系统升级后 node:sqlite 行为更严格

### 修复
1. 删除旧数据库 `~/.hermes-web-ui/hermes-web-ui.db` 让系统重建
2. 重新构建 Web UI 项目

### 问题2：版本升级
- 从 **v0.4.7**（2026-04-25）升级到 **v0.5.2** 过渡
- 最终升级到 **v0.6.10**（最新版，改名为 Hermes Studio）
- 因 GitHub 网络不稳定，通过 `npm pack` 下载 tgz 包本地解压安装
