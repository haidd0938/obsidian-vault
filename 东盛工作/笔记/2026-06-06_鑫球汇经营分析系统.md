|------|------|
| 实际收入 | 42,265元 |
| 房租（季31,633/3） | -10,544元 |
| 水电 | -2,000元 |

| 进货成本 | -12,513元 |

| **净利润** | **1,984元（净利率4.7%）** |

**说明**：14,437元"花费支出"包含商品进货成本和消耗品。从进货单反推动货成本12,513元，纯消耗品1,924元。5月烟品压货导致月利润偏低，库存后续变现后实际会更高。

### 关键诊断
1. 🔴 **月固定成本25,844元**（房租+水电+工资）占收入61%，收入一降就亏
2. 🟡 **商品毛利率24.2%**，因为上了利润薄的烟降低综合毛利率
3. 🟡 2月峰值55,318元，当前低约1.3万
4. 💡 周六日均2,023元是周一1,109元的1.8倍
